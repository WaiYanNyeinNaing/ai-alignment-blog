> *"တူညီတဲ့ AI ကို တူညီတဲ့မေးခွန်းမေးပေမယ့် — သူ့ကိုဘယ်သူလို့ပြောထားသလဲဆိုတာပေါ်မူတည်ပြီး လုံးဝကွဲပြားတဲ့အဖြေတွေရနိုင်တယ်။"*

ဒီဝါကျဟာ AI alignment က သီအိုရီပြဿနာမဟုတ်ဘူးဆိုတဲ့ အရိုးရှင်းဆုံးသက်သေပါ။ ဒါဟာ ဒီနေ့ AI စနစ်တွေနဲ့ အပြန်အလှန်ဆက်သွယ်မှုတိုင်းကို သက်ရောက်မှုရှိတဲ့ လက်တွေ့ပြဿနာတစ်ခုပါ။

ဒါကိုသက်သေပြဖို့ တိုက်ရိုက်သရုပ်ပြချက်တစ်ခုကို ကျွန်တော်တည်ဆောက်ခဲ့တယ်။

---

## တိုက်ရိုက်သရုပ်ပြချက်

[**Alignment Bias Demo ကို ဝင်ကြည့်ရန်**](https://theo-wai-prototype.vercel.app/demo/bias-demo.html)

ဖွဲ့စည်းပုံက ရိုးရှင်းပါတယ်:

- **ဘောင်နှစ်ခု**၊ ဘေးချင်းကပ်
- နှစ်ခုလုံးက **မော်ဒယ်တစ်ခုတည်း** (Gemini 2.5 Flash) ကိုခေါ်တယ်
- နှစ်ခုလုံးက **တူညီတဲ့ user prompt** ကိုလက်ခံတယ်
- **System prompt** တစ်ခုတည်းသာ ကွဲပြားတယ် — တစ်ခုက စွန့်စားမှုကိုအားပေးတယ်၊ နောက်တစ်ခုက သတိထားဖို့အလေးပေးတယ်

မေးခွန်းတစ်ခုခုရိုက်ထည့်ပြီး မော်ဒယ်တစ်ခုတည်းက အဖြေနှစ်မျိုးပေးတာကိုကြည့်ပါ။ AI က မညီညွတ်တာမဟုတ်ဘူး — သူက ကိုယ်ရည်ကိုယ်သွေးနှစ်မျိုးအတွက် *align* လုပ်ထားခံရတာပါ။

---

## သင်မြင်ရမည့်အရာ

ဒီမိုထဲက career advice ဇာတ်လမ်းကိုစမ်းကြည့်ပါ:

**User prompt:** *"ကျွန်တော် လက်ရှိ 9-5 အလုပ်ကနှုတ်ထွက်ပြီး Miami မှာ food truck စားသောက်ဆိုင်စဖွင့်ချင်တယ်။ ဘာလုပ်သင့်သလဲ။"*

**ဘောင် A (အားပေးတဲ့ system prompt):** စွန့်စားဖို့ပြောမယ်။ စိတ်အားထက်သန်မှု၊ ဘဝအဓိပ္ပာယ်၊ အမေရိကန်အိပ်မက်တွေအကြောင်းပြောမယ်။ ရဲရင့်တယ်လို့ခံစားရအောင်လုပ်မယ်။

**ဘောင် B (သတိထားတဲ့ system prompt):** ငွေစုဆောင်းမှုအကြောင်းမေးမယ်။ စားသောက်ဆိုင်အသစ်တွေရဲ့ကျရှုံးနှုန်းတွေပြောမယ်။ ဘေးထွက်လုပ်ငန်းအဖြစ်စမ်းကြည့်ဖို့အကြံပေးမယ်။

လူတစ်ယောက်တည်း။ မေးခွန်းတစ်ခုတည်း။ မော်ဒယ်တစ်ခုတည်း။ အဖြေနှစ်မျိုးလုံးဝကွဲပြား။

ဒါက bug မဟုတ်ဘူး။ LLM တွေအလုပ်လုပ်ပုံရဲ့ သဘာဝ feature တစ်ခုပါ — ပြီးတော့ alignment က ဘာကြောင့်ခက်ခဲတယ်ဆိုတဲ့ အကြောင်းရင်းလည်းဖြစ်တယ်။

---

## ဒီကနေ Alignment အကြောင်းဘာတွေသိရသလဲ

### ၁။ System Prompts တွေဟာ Alignment ပါ

AI ကုမ္ပဏီတစ်ခုက သူတို့ model ကို "align" လုပ်ပြီးပြီလို့ပြောတဲ့အခါ — တကယ်တော့ သူတို့ဟာ system prompt ရှည်ကြီးတစ်ခုကိုရေးပြီး RLHF နဲ့ လေ့ကျင့်ထားတာပါ။ System prompt ဟာ ဒီနေ့ AI စနစ်တွေမှာ alignment ရှိတဲ့နေရာဖြစ်တယ်။

System prompt ကိုပြောင်းရင် alignment လည်းပြောင်းသွားတယ်။ မော်ဒယ်တစ်ခုတည်းကို သတိထားတတ်သူ၊ ရဲရင့်သူ၊ ကရုဏာရှိသူ၊ ရက်စက်သူ၊ ဖန်တီးနိုင်သူ၊ စာသားအတိုင်းလိုက်တတ်သူ — အဖြစ်ပြောင်းလဲနိုင်တယ်။

### ၂။ Evaluator ရဲ့ ကန်းကွက်

သုတေသီတွေက model က "safe" ဟုတ်မဟုတ်စမ်းတဲ့အခါ သူတို့ရဲ့ကိုယ်ပိုင် system prompts တွေနဲ့ပဲစမ်းလေ့ရှိတယ်။ ဒါပေမယ့် user က system prompt ကိုပြောင်းလိုက်ရင်ကော။ အနာဂတ် model တစ်ခုက သူ့ကိုယ်သူ system prompt ရေးတတ်သွားရင်ကော။

Alignment faking စာတမ်း [\[1\]](https://arxiv.org/abs/2412.14093) က models တွေဟာ training မှာပုံစံတစ်မျိုး၊ deployment မှာနောက်တစ်မျိုးပြုမူနိုင်တယ်ဆိုတာပြခဲ့တယ်။ ဒီဒီမိုက ပိုရိုးရှင်းတဲ့ဗားရှင်းကိုပြတယ်။

### ၃။ တာဝန်ပြဿနာ

တူညီတဲ့ AI က ဆန့်ကျင်ဘက်အဖြေတွေပေးနိုင်ရင် — ဘယ်သူကတာဝန်ယူမလဲ။

- Model တည်ဆောက်သူလား။ (System prompt ကိုရေးတယ်။)
- User လား။ (မေးခွန်းကိုမေးတယ်။)
- System prompt engineer လား။ (ကိုယ်ရည်ကိုယ်သွေးကိုရွေးတယ်။)

ဒီမရှင်းလင်းမှုဟာ လူအများစုမစဉ်းစားမိတဲ့ လက်ရှိ AI စနစ်တွေရဲ့ အင်္ဂါရပ်တစ်ခုပါ။
